## 2. Zero-to-hero map

**What it is:** a local single-user web app (stdlib Python + one HTML page) that pairs two saved text sources from different tags, asks an LLM (via OpenRouter) for a non-obvious usable connection, scores it for novelty in up to 3 rounds, and lets you Keep it as an Obsidian note, Chain it against a third source, or run the REVEAL / BUILD / DELIVER filter.

| Piece | Lines | Role |
|---|---|---|
| `server.py` | 495 | Whole backend. `ai()` is the only OpenRouter call site. Domain: `classify`, `by_tag` (cached), `two_tags` (sqrt-weighted), `dig`, `run_filter`, `keep`, `set_tag`. Flat route table in `Handler.do_POST`. Origin guard on POST. Error taxonomy 400/403/404/409/502/500. |
| `index.html` | 268 | Whole UI. Vanilla JS, DOM nodes only (no `innerHTML` for model text). One action at a time via `busy()`. |
| `import.py` | 444 | CLI. Streams ChatGPT + Claude export zips, user turns only, two passes (idea, then `--technique` on the idea pass's drops), resumable via `import-*.log`. |
| `retag_commerce.py` | 148 | Finished one-off; kept for `--undo`. Now reuses `server.set_tag`. |
| `test_*.py` ×5 + `Makefile` + CI | ~700 | No-network self-checks. CI workflow runs `make test`. |
| `config.json` | 3 keys | `model`, `vault`, optional `data_collection`. Re-read every call. Local and gitignored (`config.example.json` tracked). |
| `sources/` | 2,047 files | 1,128 ai-practice · 459 creative-projects · 260 content-topics · 101 essays · 67 brand-frameworks · 32 commerce · 0 other. Median body 186 chars. |

**Data flow:** `Save` → classify (1 call) → file. `Dig` → `/api/pick` (labels only) → `/api/insight` (1 connect + 1–3 judge calls) → card. `Keep` → one `.md` note with frontmatter (`date`, `score`, `tags`, `sources:`) and unresolved `[[label]]` wikilinks.

**State of the work (from `roadmap.md`, verified):** Phase 0, 1, 2 shipped. Phase 3 item 0 (sqrt sampling) shipped. Phase 3 items 1–4 and Phase 4 are unbuilt and, by decision, gated behind one real MAKE cycle.

## 6. Where this lands against your instincts

- **Trap 2 (toolchain as buffer) and Trap 4 (documentation that costs more than it saves)** both describe this repo right now: three bulk corpus passes (idea, technique, commerce) and 3.5k lines of docs, 1 kept note. `roadmap.md`'s gate is the right correction, and I recommend keeping it.
- **Rule 28 (know what your tools check):** the novelty score is the model grading its own work. The card already says "self-rated"; the fix is grading data (A2), not a better label.
- **Rule 19 (nothing gets wasted):** unkept digs vanish. The ledger (A1) is this rule.
- **Rule 13 / 16 (critique first; never accept the first version):** supports a critic pass (Q3).
- **Rule 14 (volume first, then narrow):** supports Fan mode (Q4).
- **Rule 24 (go after blind spots):** the connect prompt never says so; add it (Q2).
- **Rule 26 (three gates):** `GATES` is hardcoded; fine for one brand (Lenses, Q5).
- **Rule 2 (one tool produces the final artifact):** the tool stops at an insight; A3 makes it produce the draft.
- **Tension to decide:** "comprehensive, exceptional tool" pulls toward Trap 1/2. The sequencing in §8 keeps the build inside one burst per tier and puts a real-use gate between tiers.

## 7. Enhancements and solution proposals
